# Telemedicine-risk-stratification-analytics
Built a telemedicine analytics project to predict high-risk patients and engagement probability using machine learning. Performed data cleaning, feature engineering, and classification modeling. Segmented patients for targeted outreach and simulated A/B testing to evaluate personalized messaging impact.

# Project Overview

Telemedicine platforms generate large volumes of patient interaction data. This project leverages that data to:

Predict which patients are high risk

Identify who needs urgent care

Forecast engagement likelihood

Optimize outreach using A/B testing

Visualize insights through an interactive dashboard

The goal is to improve patient outcomes while maximizing telehealth engagement efficiency.

# Business Objectives

✔ Identify patients requiring proactive outreach
✔ Predict patients at risk of non-engagement
✔ Improve telehealth usage rates
✔ Reduce emergency escalations
✔ Measure impact of personalized communication
